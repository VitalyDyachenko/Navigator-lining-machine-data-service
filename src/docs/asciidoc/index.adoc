== Формат ответа с ошибкой

При возникновении ошибки все эндпоинты возвращают JSON-объект единого формата:

[cols="1,1,3,2", options="header"]
|===
| Поле | Тип | Описание | Пример

| `timestamp`
| `String`
| Дата и время формирования ошибки в формате ISO-8601 со смещением часового пояса.
| `2026-11-26T21:21:46.805333500+07:00`

| `status`
| `Number`
| Числовой HTTP-статус ответа.
| `404`

| `code`
| `String`
| Машиночитаемый код ошибки. Для всех описанных тут случаев ошибок он будет тем же самым, что в примере этого случая.
| `WORK_NOT_FOUND`

| `message`
| `String`
| Читаемое описание причины ошибки. Для всех описанных тут случаев ошибок он может отличаться от примера этого случая.
| `Work with id 999 not found`

| `path`
| `String`
| URI запроса, при обработке которого произошла ошибка.
| `/api/works/999`

| `traceId`
| `String`
| Идентификатор запроса для поиска в логах (дублируется в заголовке ответа `X-Trace-Id`). Может быть `null`.
| `64922353-2c99-4c3e-92f3-ca22e49ae11b`
|===

== Работа с файлами работ

:op-title: Загрузить файлы работы
:op-id: work-files/upload
:op-note: Требования к входным файлам: + \
`surveyFile` — файл съёмки с расширением `.srv` (сигнатура `NavSRV`) + \
`calculationFile` — файл проекта с расширением `.prm` (сигнатура `NavPRM`) + \
`correctionFile` — файл выправки с расширением `.crm` (сигнатура `NavCRM`) + \
Максимальный размер 1 файла: 10 МБ + \
Максимальный суммарный размер всех файлов: 30 МБ + \
Сервер физически не принимает файлы большего размера и сбрасывает сетевое соединение. Фронтенд обязан проверять размер до отправки запроса.
